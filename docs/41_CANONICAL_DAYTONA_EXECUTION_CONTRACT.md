# Canonical Daytona lifecycle contract

Depends on 36, 40. The only production proof command is `printf '%s\\n' 'PHASE_5_EXECUTION_PROOF_OK'` (actual command has one backslash before n). Only low-risk execution with `code_mode`, no metadata, blocked network, ten-minute TTL, no arbitrary command, cancel or retry. A successful result requires sandbox started, session ID, command ID, exit code zero, exact stdout `PHASE_5_EXECUTION_PROOF_OK` plus newline, empty stderr, matching logs, independently observed stopped state, successful delete, and a separate authoritative post-delete 404. An accepted stop/delete response, timeout, or TTL is **not** proof. If cleanup is uncertain, persist unknown and use the narrowly scoped operator sandbox reconciliation endpoint; never fabricate post-delete verification or resubmit the same key. Runtime secret `DAYTONA_API_KEY` must never be logged or reflected. Live results must be recorded as evidence, not inferred from mocks.
