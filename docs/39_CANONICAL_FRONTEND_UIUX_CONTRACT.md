# Canonical frontend/UI contract

Depends on 36, 38. The responsive same-origin console at `/` has ephemeral operator login, overview metrics, execution history, proof form, execution detail and durable audit timeline. Only the approved Cloudflare token authenticates the operator bridge. Browser memory is cleared on logout or refresh; never store credentials in localStorage, cookies, URLs, source or logs. All dynamic API values must be inserted as text, not HTML. The proof form generates a high-entropy idempotency key in the browser; replay uses the same key, conflict modifies the locked canonical request in the server without submitting another provider job. Loading, empty, unauthorized, conflict, unknown, and network-error states must be visible. Unknown outcomes expose a narrowly scoped provider cleanup reconciliation action in the detail view; this never reruns the command. UI does not claim a proof passed until D1 reports verification. A fixed CSP, no third-party scripts, and same-origin fetch protect the console. Support mobile/tablet/desktop without overflow in navigation, forms, or tables.
