# Canonical database contract

Depends on 36. Cloudflare D1 binding `DB` references `genspark-execution-bridge-gateway`. Schema authority is `migrations/0001_gateway.sql` and `migrations/0002_operator_durability.sql`. Tables: `gateway_idempotency` (unique hashed key, actor, request fingerprint, task ID; never automatically removed), `gateway_tasks` (actor, request, state, policy, command digest), `gateway_executions` (task FK, provider ID, state, verification, result code), `gateway_audit` (redacted correlation events), `gateway_durability_proof` (operator-only synthetic diagnostic). Index `idx_gateway_audit_task` accelerates task audit. Records must survive distinct HTTP requests. No raw secrets, arbitrary SQL endpoint, raw output, or browser-only persistence. No deletion of historical proof records from product UI; durability diagnostic is not a general CRUD API. Reservation uniqueness is atomic via D1. If reservation exists without task after crash, replay stays unknown and never retries provider execution.
