# Canonical testing, security and deployment contract

Depends on 36–41. Run `npm test`, `npm run typecheck`, `npm run build`; tests cover D1 reservation/reads, auth, policy denial, exact output and cleanup, replay/conflict, UI delivery, and protected routes. Audit XSS, SQL injection, command injection, arbitrary URLs, secret leakage, CSP, IDOR, unsafe debug routes, and provider ambiguity. Development preview uses PM2 port 3000 and local D1 only. Production is Cloudflare Pages BYOK on branch `main`; use the project's Deploy-panel API token, verify `wrangler whoami`, apply D1 migrations remotely, deploy `dist` to the configured Pages project and smoke-test the actual production URL. Push to the existing GitHub repository after authenticated setup, never push credentials. Do not claim production E2E or Daytona PASS without live independently verified provider evidence. Record exact blockers and final commit SHA. Production provider errors must not expose stack traces or secrets.
