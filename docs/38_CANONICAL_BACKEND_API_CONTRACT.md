# Canonical API and authentication contract

Depends on 36–37. `GET /` is public operator login shell, without embedded secrets. `GET /health` public redacted capability status. `GET|POST /mcp` legacy read-only proof resources. `POST /execute` and `GET /executions/:task_id` require the runtime `GATEWAY_OPERATOR_TOKEN` bearer; proof body contains only strict canonical task and idempotency key. `GET /operator/executions` lists at most 50 operator-owned task summaries. `GET /operator/executions/:task_id` reads owner-scoped state/audit. `POST /operator/proof|replay|conflict` take only JSON `{idempotency_key}` and internally construct the locked task. `POST /operator/durability` and `GET /operator/durability/:id` perform a narrowly scoped synthetic D1 check. `GET|POST /operator/sandbox/:task_id` inspects/reconciles only a correlated proof sandbox. All `/operator/*` routes require a live approved Cloudflare user token ID and account match against official Cloudflare endpoints; the token is never persisted. This is a single operator system, not a self-registration product. Login is verified by the protected list endpoint; logout discards the token in memory. HTTP errors: 400 invalid, 401 unauthenticated, 403 policy denied, 404 unknown, 405 wrong method, 409 idempotency conflict, 503 unavailable; uncertain provider outcomes return 202 with explicit unknown state. No frontend privilege can override backend policy.
